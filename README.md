# MemoryTalk（Android）

与逝去亲人对话的 AI 软件。微信风格界面，原生 Android（Kotlin + Compose），纯文字对话。

> **重要**：这是基于你提供资料生成的 AI 模拟，不是逝者本人。请阅读下方「安全边界」。

## 功能

- 微信风格：聊天列表、聊天窗、通讯录、我、人设编辑、设置
- 人设可配置：称呼、名字、关系、性格、说话风格、生活习惯、共同回忆、不愿谈及、补充
- **双 AI 安全架构**：聊天 AI 生成回复 → 审查 AI 审核 → 通过后显示；不通过则安全改写；审查失败则拦截（fail-closed）
- 本地存储：人设、对话、设置全部存 App 私有目录，不上传

## 编译

需要 JDK 17、Android SDK 34、Gradle 8.7。

```bash
# 修改 local.properties 里的 sdk.dir 为本机 SDK 路径
gradle assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`

## 使用

1. 安装 APK
2. 进入「我 → 设置」填写 API Key（支持任何 OpenAI 兼容服务，默认 DeepSeek）
3. 返回「微信」页，点右上角 ＋ 新建人物
4. 填好资料后进入聊天

API Key 只存本机，源码中无任何密钥。

## 双 AI 架构

```
用户消息 → 聊天 AI 生成回复 → 审查 AI 审核 → 通过后显示
                                ↓ 不通过
                         拦截 + 安全改写
```

- **聊天 AI**：按人设生成自然对话。
- **审查 AI**（安全护栏核心）：检查每条回复，拦截身份欺骗、危险引导、编造事实、情感操控、依赖诱导。审查服务故障时 fail-closed，不推送原文。
- 两层 AI 都在 App 内调用，绕过界面也无法关闭审查。

## 安全边界

- 身份诚实：禁止自称真人、天堂视角；被问到如实说明是 AI 模拟
- 危机干预：识别轻生/自残信号 → 停止角色扮演 + 心理援助热线
- 不编造事实：不确定就说「记不清了」
- 不提供医疗、法律、财务、危险行为建议
- 每 20 轮温和提醒联系现实亲友

审查 AI 可在设置中关闭（仅保留规则层防护），默认开启。审查模型默认与聊天模型相同，可单独指定。
